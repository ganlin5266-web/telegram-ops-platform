# 第二阶段第 1 批 UI 交付范围

唯一仓库 ganlin5266-web/telegram-ops-platform。基线为后端提交 `2f15b89dfd5c59d66784caa702e315278254d13e`。本批独立新增 `web/`，核心 `src/`、`db/` 和既有后端测试不变。

| 项目 | 实现与验收 |
|---|---|
| 前端 | React、TypeScript、Vite；独立 package-lock、构建和测试 |
| 登录 | 中文账号密码表单，真实 Session Cookie，统一失败提示，无注册/找回/MFA |
| 身份与权限 | /me、/me/permissions，按当前 brandId/botId 获取有效权限；不推断角色 |
| 运营范围 | 授权品牌与 Bot API；切换同步清理列表、详情、积分与操作，旧响应失效 |
| 总览 | 实际身份、范围、状态、默认语言和 API 访问状态，无虚构指标 |
| 用户 | 真实用户字段和 Telegram ID 字符串；50 条游标批次，历史游标上一批/下一批 |
| 积分 | 真实余额字符串；BigInt 预计余额；原因和备注合并 note，500 字符限制 |
| 写操作 | points.adjust 权限入口，二次确认，服务端事务，成功后重新读取余额 |
| 幂等 | 每次新操作独立 UUID；重试沿用 eventId、Idempotency-Key 与完整请求内容 |
| 会话失效 | 401 清空身份、CSRF、范围、详情和列表，回到登录，不重放写操作 |
| 权限失效 | 403 清空当前数据与权限，中文提示，提供重新加载授权范围 |
| 请求状态 | Loading/Empty/Error/Success；20 秒网络超时；安全中文错误映射 |
| 手机端 | 390px 浏览器验收、抽屉导航、横向表格、固定操作列和全屏详情 |
| 语言 | 后台中文；展示真实 Bot/用户语言代码，未写语言或模板接口 |
| 安全 | 无 Storage 凭证持久化、无密码日志；Session HttpOnly、CSRF 内存、真实响应敏感字段检查 |
| 测试数据 | 生产前端无 Mock；组件测试有明确 fixtures，E2E 使用真实服务和隔离数据库种子数据 |
| 本地验证 | 31 项组件测试、5 项真实 API 浏览器测试；前后端构建；后端 46 通过、12 PG 专用跳过 |
| CI | 保留 PostgreSQL 17 版本检查、重复 Migration、原有 58 项；新增前端构建、31 项组件及 5 项 PostgreSQL 浏览器验收 |

实际 CI 结论请对照本批最终 commit 的 [core-ci](https://github.com/ganlin5266-web/telegram-ops-platform/actions/workflows/ci.yml) 运行记录。CI 上传前后端测试日志作为证据，不能将本地 PGlite 跳过项计为 PostgreSQL 通过。

## 当前边界与后续建议

本批现有 API 足够完成已开放功能。尚无正式生产管理员、真实授权品牌/Bot配置或生产部署；正式接入由负责人按既有运维文档准备。当前 API 不提供搜索/总数/全量导出/流水列表/运营指标，不制作这些虚假入口。

网络结果不确定的写操作在当前详情内保留重试标识；刷新页面或结束会话后不会自动恢复/重放写操作。关闭前提示核对业务结果。后续可由服务端提供操作查询/流水 API，改善异常操作核查。

建议下一批先补用户服务端搜索、积分流水只读查询和审计查询，再实现相应只读页面。本批停止，不开发活动、兑换 UI、菜单模板编辑或消息发送。
